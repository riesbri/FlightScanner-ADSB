# Security Policy

## Supported Versions

Only the latest commit on `main` is actively maintained.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately via GitHub's built-in security advisory feature:
**Security → Report a vulnerability** in the repository's *Security* tab.

I'll acknowledge within 72 hours and aim to publish a fix within 14 days for confirmed issues.
